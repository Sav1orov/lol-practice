# Rune Lab — самостоятельная практика Nuxt

## Что должно получиться

Приложение будет уметь:

- показывать каталог чемпионов;
- искать чемпионов по имени;
- фильтровать их по роли;
- открывать динамическую страницу чемпиона;
- показывать рекомендованные руны и заклинания призывателя;
- добавлять чемпионов в избранное;
- сохранять избранное между перезагрузками;
- принимать пользовательское предложение нового билда;
- показывать локальные ошибки без падения всей страницы;
- устанавливать SEO-метаданные;
- иметь одну Storybook-story и один E2E smoke-тест.

Дополнительная функция, похожая на сайты со сборками: пользователь сможет выбрать стиль игры — `safe`, `standard` или `aggressive` — и увидеть соответствующий вариант рун.

## Важное правило

Не выполняй весь список сразу. Закончил одно задание — запусти проект, проверь результат и сделай коммит.

- Используй `interface` для объектов и `type` для строковых union-типов.
