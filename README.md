# Rune Lab

Учебный Nuxt-проект: каталог чемпионов League of Legends с рекомендованными рунами.

Главная цель — самостоятельно написать код и разобраться, как связаны страницы, компоненты, типы, composables, серверные API, cookies, middleware и тесты.

Готового приложения в репозитории нет. Здесь находится только минимальный Nuxt-каркас и маршрут обучения.

## Запуск

```powershell
npm install
npm run dev
```

После запуска открой `http://127.0.0.1:3001`.

## Как проходить задания

1. Открой `docs/LEARNING-ROADMAP.md`.
2. Выполняй только одно задание за раз.
3. Не копируй решение целиком из старого проекта.
4. После каждого задания проверь критерии готовности.
5. Если застрял, сначала попроси намёк, а не готовый код.
6. Делай отдельный Git-коммит после каждого законченного задания.

## Правило помощи

Можно просить помощь четырёх уровней:

1. «Объясни ошибку» — только причина.
2. «Дай маленький намёк» — название нужного API или направление.
3. «Покажи псевдокод» — алгоритм без готового Vue-кода.
4. «Покажи решение» — готовый код только когда другие варианты не помогли.
